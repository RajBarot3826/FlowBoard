# 🚀 FlowBoard — Smart Kanban Task Manager

A beautiful, fully-functional Kanban board task manager built entirely with **voice-driven development** using [Whispr Flow](https://wisprflow.ai).

![FlowBoard Screenshot](https://img.shields.io/badge/Status-Live-brightgreen) ![Built With](https://img.shields.io/badge/Built%20With-Whispr%20Flow-blueviolet) ![License](https://img.shields.io/badge/License-MIT-blue)

---

## ✨ Features

- **🗂️ Kanban Board** — Drag-and-drop tasks between To Do, In Progress, and Done columns
- **➕ Full CRUD** — Create, edit, and delete tasks with a clean modal form
- **🎯 Priority Levels** — High (🔴), Medium (🟡), and Low (🟢) priority badges
- **📅 Due Dates** — Set deadlines with overdue highlighting
- **🔍 Search & Filter** — Real-time search + filter by priority, due today, or overdue
- **📊 Statistics Dashboard** — Live stats showing total, completed, overdue, and completion rate
- **🌙 Dark/Light Theme** — Toggle between themes with preference saved locally
- **💾 Persistent Storage** — All data saved to localStorage (no backend needed)
- **🔔 Toast Notifications** — Visual feedback for all actions
- **⌨️ Keyboard Shortcuts** — `N` (new task), `/` (search), `Esc` (close modal)
- **📱 Fully Responsive** — Works beautifully on desktop, tablet, and mobile
- **🎨 Premium UI** — Glassmorphism, smooth animations, and polished design

## 🚀 Quick Start

### Option 1: Just Open It
```
Simply open index.html in your web browser!
```

### Option 2: Use a Local Server
```bash
# Using Python
python -m http.server 8000

# Using Node.js
npx serve .

# Using PHP
php -S localhost:8000
```

Then visit `http://localhost:8000` in your browser.
