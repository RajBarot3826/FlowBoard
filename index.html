🎙️ Voice Commands & Hotkeys Guide

⚡ Voice Commands (Press 'V' to Activate)

FlowBoard comes with native speech recognition. Speak any of these commands naturally:

Say Something Like... Action Performed
"Create task build user profile due tomorrow" Adds a new task with automatic date parsing
"Add high priority task fix memory leak" Creates a task tagged with High Priority
"Search authentication" Filters board in real-time
"Filter high priority" / "Filter overdue" Applies priority or date filters
"Switch to dark mode" / "Light mode" Changes UI color theme
"Export backup" Triggers JSON backup download
"Clear filter" / "Show all" Resets search and active filters
